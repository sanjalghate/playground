Similar Siblings (LCNC-22866)

1. Loop target: 4 similar buttons

Record a click on "Main 1" and make it a "For each element" loop (4 similar). Each button has its own id, data-index and aria-label, so Configure attributes can narrow the set to 1 or 0.

2. Different set: 3 other buttons

For Override default locator: set the loop step XPath to //button[@class="other-btn"] (3 different elements). If the run still logs main-1..4, the override is ignored.

3. Zero-match XPath

No element on this page has class "ghost-btn". Override the loop step XPath to //button[@class="ghost-btn"] (0 matches). Expected: 0 iterations.
